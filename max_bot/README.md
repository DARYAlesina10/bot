# MAX bot copy

Это отдельная копия бота для мессенджера **MAX**.

## Что сделано
- Скопирован текущий функционал Telegram-бота в `max_bot/bot_max.php`.
- Основной Telegram-бот в корне проекта не изменяется.
- Конфиг копии вынесен под MAX:
  - `MAX_BOT_TOKEN`
  - `MAX_API_URL`

## Быстрый старт
1. Настрой переменные окружения:
   - `MAX_BOT_TOKEN`
   - `MAX_API_URL` (endpoint API MAX)
2. Направь webhook MAX на `max_bot/bot_max.php`.
3. Проверь, что у бота есть права на чат поддержки и треды (если MAX использует аналогичные сущности).

## Важно
Внутренняя бизнес-логика полностью скопирована из Telegram-версии.
Если в MAX отличаются названия/формат API-методов, нужно сопоставить их в функции `tgRequest()` внутри `bot_max.php` (сигнатура сохранена специально для простого порта логики).
